# Lune

The public pages for Lune, live at <https://jonlabrie.github.io/lune/>: [the pitch page](https://jonlabrie.github.io/lune/) and [how it works](https://jonlabrie.github.io/lune/how-it-works.html).

Lune shows, in the viewer you already use, whether a value on screen still matches the value that was recorded.

These are static pages with no build step, server or script. Contact: lune.development@gmail.com
